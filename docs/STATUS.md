# Current Status — what's real, what's fake, what's broken

_Originally an audit of commit a70453a (2025-12-08). Last updated 2026-11-22. Update this file as items change._

## Summary

**Milestones 0–2 are done** (two Milestone 0 items deferred by the owner: a separate preview database, now blocking Milestone 3, and moving Neon off Azure). The site has email/password and Google sign-in, onboarding, a curated directory of admin-verified Every.org nonprofits with follow/unfollow, a feed of sourced news, a dashboard with real (honest) numbers, the "Why give" cards, and rate limits.

What's missing is real money movement: every donation is still a PENDING intention ("recorded, not yet paid"). Every.org checkout and webhook groundwork exists behind a flag that is off on production (Milestone 3). The private profile page (Milestone 3.5) and local nonprofits (Milestone 3.6: area filter, volunteering, regions, Near me) are built; next after Milestone 3 is the Penny Jar (Milestone 4). No crypto or smart-contract code exists (D-000).
